01 / Final Project

Story AI Assistant · 4 chức năng bắt buộc
01

Summarization

Tóm tắt toàn bộ truyện, từng chương hay nhóm chương; giữ đúng nhân vật, diễn biến và thứ tự thời gian.

02

Question Answering

Hỏi: “Ai đã cứu nữ chính ở chương 5?” — chatbot tìm và trả lời theo nội dung truyện.

03

Plot Explanation

Giải thích động cơ hoặc chuỗi sự kiện, kèm trích dẫn chương/đoạn làm bằng chứng.

04

Scene Illustration

Chọn đoạn truyện → trích xuất cảnh → tạo prompt → sinh ảnh minh họa bằng mô hình ảnh.

05 / Technology Stack

Python thuần: Gemini API cho LLM, các thư viện lõi chạy trên máy
Thành phầnCông cụ gợi ýVai trò
PipelinePython thuần (không dùng công cụ low-code hay framework như LangChain)Tự viết loader, chunker, retrieval và router giữa các chức năng; in "dấu vết" mỗi truy vấn để quan sát pipeline
LLMGemini API (SDK google-genai)Tạo câu trả lời, tóm tắt, phân tích
EmbeddingEmbedding model đa ngôn ngữ chạy local (vd bge-m3), so sánh với Gemini embeddingBiến đoạn truyện thành vector ngữ nghĩa
Vector DBChromaLưu chunks, metadata và truy vấn tương đồng
Image generationGemini image model hoặc local diffusion model (quyết định ở V5)Sinh ảnh từ prompt cảnh truyện
UIStreamlitGiao diện chatbot demo
Gemini API ở free tier có giới hạn tần suất (rate limit) và dữ liệu gửi lên có thể được Google dùng để cải thiện sản phẩm (hãy kiểm tra điều khoản hiện tại). Vì vậy embedding chạy local để không phải gửi toàn bộ truyện lên; chỉ các đoạn được truy xuất mới gửi cho LLM. Chạy local cần tài nguyên RAM/GPU và điện. Phần sinh ảnh thường nặng nhất; đánh giá khả năng phần cứng và chi phí trước khi chốt scope demo.
